## 数据口径

- 年份取 `finishedDate` 的有效 ISO 日期 `YYYY-MM-DD` 或 ISO 时间戳的日期部分；不使用修改时间或入库时间补齐。无效日期、空字段进入未知日期分组。
- 年份筛选按字段值匹配，不隐式更改阅读状态筛选；例如带日期的“在读”书仍可按年份找到。
- 年度数量和阅读途径分布只统计归一化状态为“读完”的藏书。未知日期仍计入已读总数与途径分布。途径空字段独立显示，不猜测途径。
- 新统计使用全部藏书，与原有编辑活动的周／月／年／全部范围独立，并在界面明确标注。活动热力图仍表示编辑记录。
- 缓存仅保存外部书籍元数据，不缓存书籍笔记或阅读记录；7 天有效期、最多 200 项。失败、null、空列表不缓存；读写失败不阻断查询。没有离线兜底或过期数据回退。
- 清空命令为“清空书籍元数据缓存”；清空时进行中的旧请求不会重新写回缓存。
